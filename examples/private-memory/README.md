# Private memory procedure example

Copy this directory into your private operations project. These are fictional
values, not a runnable target or credential set. Execution and mutations start
disabled. The zero inspector digest must be replaced with the reviewed artifact's
actual SHA-256; never disable certificate or SSH verification.

Install the exact core/integration revisions in the catalog dependency locks.
Build the native inspector with the integration's documented builder, then set
its path, digest, matching package checkout and actual controller tool paths.
Obtain host fingerprints and SSH trust over an already trusted channel. Select
one actually owned running LXC and its existing generation tags; Terraform-owned
fields are outside this procedure. Do not copy tags onto an unrelated guest.

Create both owner-only scratch/state directories in the private project. Use the
same durable state directory for controllers that must share subject locks.
Replace the request, desired memory and explicit capacity reserve. The sample
one-GiB reserve is an example, not a universal policy or capacity reservation.

Follow the [operation walkthrough](../../operations/proxmox-lxc-memory-grow/README.md).
Local input validation does not contact the host; planning does read current
remote state and writes private context. Retain its evidence outside public Git.
